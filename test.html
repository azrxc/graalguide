How to use the mapping table

Each animation uses a specific row in your sprite sheet. Set the index for each animation and direction to match your sprite sheet layout (0 = top row).

Head offset tuning

Use the X and Y sliders to align the head perfectly with the body. Negative Y values move the head up, positive moves it down.

Auto Fit feature

The Auto Fit button will try to automatically detect the best frame mapping based on your sprite sheet dimensions.
